Canvas Tab Privacy Policy

Last updated: October 1, 2026

Canvas Tab replaces Chrome’s new-tab page with a customizable whiteboard workspace. This policy explains how the extension handles your information.

Information you add to your board

Canvas Tab processes and stores content you choose to add, including:

  • Text, notes, drawings, and checklists.
  • Uploaded images, stickers, and audio files.
  • Bookmark URLs and link names, including retrieved page titles.
  • Custom widget HTML, CSS, and JavaScript.
  • Board settings, element positions, sizes, and appearance.

This information is used to display, customize, and save your workspace.

Your board is stored locally in your browser using IndexedDB. Canvas Tab does not upload your board to a developer-operated server or provide cloud synchronization. The developer cannot access your locally stored board through the extension.

Bookmark title retrieval

When you add a bookmark without a custom name, Canvas Tab can request that webpage to retrieve its title.

This feature requires optional website permission. You may enable access to all HTTP and HTTPS websites to avoid repeated permission requests. Without permission, or if retrieval fails, Canvas Tab uses the website’s domain name instead.

Requests go directly to the website you specify. No third-party title retrieval service is used. These requests omit browser cookies and do not send a referring-page URL. The destination website nevertheless receives the requested URL and ordinary network information, such as your IP address, and may handle that information under its own privacy policy.

Canvas Tab extracts title text and does not execute the fetched page’s scripts. It does not read Chrome’s browsing history, monitor unrelated browsing, or track which bookmarks you visit.

Custom widgets and external content

Custom widget code runs in an isolated sandbox without access to extension APIs or direct access to the board.

User-supplied HTML, CSS, or JavaScript may reference external content. Where permitted by the browser and the widget’s security restrictions, loading external resources can contact the corresponding websites. Those websites may receive ordinary request information and apply their own privacy policies.

Only use widget code and external resources you trust. The developer does not automatically receive your widget code or its contents.

Analytics, advertising, and data sharing

Canvas Tab contains no built-in advertising, analytics, or behavioral tracking.

The developer does not sell your board data, use it for advertising, or transfer it for purposes unrelated to the extension’s functionality. Canvas Tab does not use your information to determine creditworthiness or for lending purposes.

External requests described above are made to websites selected or referenced by you.

Backups and retention

The Backup feature creates a local JSON download containing your board data, including embedded images, audio files, bookmarks, and widget source code. You control where this file is stored and whether it is shared.

Board data remains in your browser until you remove it or clear the extension’s storage. Uninstalling the extension may remove its locally stored data. Downloaded backup files remain wherever you saved them until you delete them.

Deleting an individual element updates the saved board, but it may remain temporarily available through undo history during the current session. Copies may also remain in backups you previously exported.

Your choices

You can edit or remove board content, export a backup, and revoke website permissions through Chrome’s extension settings. Revoking website access does not delete existing bookmarks.

To remove stored board data completely, clear the extension’s browser storage or uninstall the extension. Delete any exported backups separately.

Security

Canvas Tab uses Chrome’s extension security model and isolates custom widget execution in a sandbox. Local storage and exported backups are not separately encrypted by Canvas Tab. Anyone with access to your browser profile or backup files may be able to access their contents.

Limited use

Canvas Tab uses information only to provide its described workspace features. Its handling of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes to this policy

This policy may be updated when the extension’s functionality or data practices change. The latest version will be published on this page with an updated date.

Contact

For privacy questions, contact the developer through the support contact provided on Canvas Tab’s Chrome Web Store listing.
